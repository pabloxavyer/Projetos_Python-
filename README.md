# 🐍 Meus Projetos e Laboratório em Python

Repositório central reunindo meus estudos, projetos e sistemas desenvolvidos em Python, explorando desde lógica de programação e estruturas de dados até soluções voltadas para a comunidade.

---

## 📁 Projetos Inclusos

### 💈 Barber Planner (v0.0.1)
Sistema de gestão para barbearias focado em organização de agenda, controle de serviços, cupons de desconto e cancelamentos.
- **Destaques:** Refatorado para trabalhar com listas de dicionários, garantindo maior integridade na gestão de clientes, dias e horários.

### 💰 Controle Financeiro Pessoal *(Em breve)*
Gerenciador financeiro open-source pensado para resolver as limitações dos aplicativos pagos do mercado.
- **Destaques:** Controle total de receitas, despesas fixas/variáveis e suporte inteligente a compras parceladas, com salvamento local em JSON.

### 🏙️ Zeldoria Sistem *(Em breve)*
Plataforma de zeladoria urbana inteligente para aproximar o cidadão da gestão pública.
- **Destaques:** Mapeamento de ocorrências via fotos e geolocalização, geração automática de relatórios técnicos com SLA e contador de reincidência de chamados.
