# 💈 Barber Planner

Aplicação em Python criada para automatizar o fluxo de agendamentos, equipe e estoque de uma barbearia.

## 🚀 Funcionalidades
- **Agendamentos:** Organização de horários e serviços.
- **Barbeiros:** Cadastro de nomes, especialidades e experiência.
- **Estoque:** Registro de produtos e cálculo do valor total.

## 🛠️ Tecnologias
- Python 3.x (Listas e Dicionários)
- VS Code & Git
