# ✈️ Sistema de Controle de Aeroporto e Bagagens

Simulador em Python para gestão, triagem e controle de bagagens e passageiros.

## 🚀 Funcionalidades
- **Registro:** Associação de bagagens a voos e passageiros.
- **Regras:** Validação de peso e limites permitidos.
- **Consultas:** Listagem em tempo real do status das bagagens.

## 🛠️ Tecnologias
- Python 3.x (Loops, Listas e Dicionários)
- VS Code & Git
