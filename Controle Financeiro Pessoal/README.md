# 💰 Controle Financeiro Pessoal (Open & Personal)

Uma solução de gerenciamento financeiro pessoal desenvolvida sob medida para resolver um problema real: **a falta de aplicativos de controle financeiro gratuitos, completos e sem restrições.**

O projeto nasceu para uso próprio, com foco em simplicidade, total controle de parcelamentos e uma interface limpa no terminal. Caso atinja uma excelente projeção e usabilidade, a ferramenta será disponibilizada publicamente para ajudar a comunidade e amigos a organizarem suas finanças de forma transparente e gratuita.

---

## 🎯 Por que este projeto existe?

- **Com a minha cara:** Construído para atender exatamente às minhas necessidades reais do dia a dia.
- **De dev para a comunidade:** Com o amadurecimento da interface e das funcionalidades, o objetivo é compartilhar a ferramenta com amigos e a comunidade open-source.

---

## 📌 Funcionalidades Planejadas

- [ ] **Cadastro de Entradas:** Registro de receitas e fontes de renda.
- [ ] **Cadastro de Saídas / Despesas:**
  - Despesas fixas e variáveis com categorização.
  - Suporte inteligente a **compras parceladas** (ex: *Lançamento automático de parcelas 1/12, 2/12...*).
- [ ] **Extrato & Visão Geral:** Visualização clara das movimentações.
- [ ] **Cálculo de Saldo Automático:** `Total de Entradas - Total de Saídas`.
- [ ] **Filtro Mensal & Histórico:** Organização por mês e ano para facilitar o planejamento.
- [ ] **Persistência de Dados Local:** Armazenamento seguro em arquivo `JSON` (seus dados continuam no seu computador).
- [ ] **Interface Amigável (Terminal):** Layout limpo e intuitivo para navegação rápida.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Estruturas de Dados:** Dicionários e Listas
- **Armazenamento:** Módulo `json` nativo
- **Manipulação de Datas:** Módulo `datetime`
