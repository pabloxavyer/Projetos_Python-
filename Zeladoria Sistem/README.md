# 🏙️ Zeldoria Sistem

Um sistema simples de **zeladoria urbana inteligente** para ajudar o cidadão a reportar problemas na cidade (buracos, iluminação, lixo) e conectar direto com a prefeitura.

---

## 🚀 Como Funciona

1. **Foto & Mapa:** O usuário tira uma foto e o sistema marca a localização exata no mapa.
2. **Relatório Automático:** O usuário descreve o problema e o sistema gera o texto com a solução sugerida e o prazo de resolução.
3. **Contador de Reclamações:** Se várias pessoas reclamarem do mesmo ponto, o sistema soma as chamadas para aumentar a prioridade.
4. **Envio:** O relatório final é enviado para a prefeitura por e-mail ou integração automática.

---

## 🛠️ Tecnologias Planejadas

- **Linguagem:** Python
- **Banco de Dados:** PostgreSQL com geolocalização
- **Mapas:** OpenStreetMap / Google Maps
