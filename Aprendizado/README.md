# 🐍 Laboratório de Estudos em Python

Este repositório é meu ambiente de testes e fixação de conceitos em Python. Aqui desenvolvo e valido lógicas, estruturas de dados e boas práticas antes de implementá-las em projetos maiores, como o **Barber Planner**.

## 📌 Conteúdos do Repositório

- **Exercícios de Fundamentos:** Variáveis, estruturas condicionais e loops (`while`, `for`).
- **Estruturas de Dados:** Manipulação avançada de Listas (`list`) e Dicionários (`dict`).
- **Aplicações Práticas:**
  - Cadastro e atualização de entidades (ex: barbeiros e especialidades).
  - Gerenciamento de estoque com cálculo automatizado do total investido.

## 🛠️ Tecnologias e Ferramentas

- Python 3.x
- Visual Studio Code
- Git & GitHub
